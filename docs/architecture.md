# App 架构

CubeginApp 是 SwiftUI 入口；LaunchRootView 叠加一次性冷启动动画；AppTabsView 拥有
首页、成绩和设置导航，ContentView 负责首页响应式布局、系统玻璃控件和计时交互。
TimerModel 是 MainActor 上的 Observable 产品状态，Engine 是后台 SDK 适配层。

Engine 封装生成打乱和获取 SVG。Rust 拥有魔方语义，App 不复制
移动规则、打乱算法或求解器。安装的 Vendor/CubeginSDK 是唯一引擎依赖。

计时以 ContinuousClock 计算时长，TimelineView 刷新显示；进入非 active 状态会取消
当前计时且不保存。按住屏幕或空格达到设置中的延迟后，数字变绿，松开开始计时。
再次按下即停止。

Solve 保存 UUID、秒数、项目、打乱、日期。成绩以 JSON 原子写入 App Documents 的
solves.json，读取与写入失败通过界面提示。存储包含 solves 与 groups，写入时整体原子替换。
读取兼容原有的成绩数组，缺少 groupID 的记录按项目归入初始分组；缺少罚时字段视为正常。
每个标准项目和完整训练 ID 都有自己的初始分组。用户可新建、重命名并设置默认分组，
同一项目只有一个默认分组。项目切换进入默认分组，当前分组切换只影响保存位置和成绩筛选。
分组选择使用 Sheet，标题居中并提供新增入口，列表支持拖拽排序和左划后在右侧显示编辑、删除。
新建与编辑在同一面板的导航栈内完成，可修改名称和默认设置。名称单行输入，最多 16 个字符，超限时提示并禁用保存；分组选择胶囊和列表名称统一单行显示，超长时尾部省略，旧长名称读取时保持完整。默认组禁止删除，
其余组删除前确认成绩数量并提示无法恢复；确认后整体原子删除该组及其成绩。
成绩详情按 UUID 从模型读取实时值，用右对齐的 +2、DNF 两个紧凑按钮修改判定，互斥选中并可再次点击取消，右上角提供删除并二次确认。成绩、判定按钮组成独立 Section，详情不额外显示原始计时，项目/分组/日期另为一组；判定行去掉额外上下 inset，保留 44pt 点击高度。支持通过下拉菜单移动到同项目其他分组（无目标时不可点击，不提供新增）。独立的详情导航不会因移动离开当前列表而退出。打乱文本与打乱图合并在同一 Section，不显示额外标题，底部复用 SVGView 并将图像水平、垂直居中；计时页保留原来的右下对齐。Engine 在后台按该成绩保存的项目/打乱调用 SDK evaluateEvent 生成打乱图，加载失败显示提示。
分组顺序与成绩一并持久化，旧成绩通过初始组 ID 参与筛选及删除。
关闭分组列表的整行拖拽交互，仅右侧拖拽柄的 UIKit 长按手势可发起原生交互排序，
通过 List.onMove 保存结果；长按名称不调序，拖拽取消不写入顺序。
停止后可对刚完成的成绩加 2 秒、标为 DNF 或删除；两种标记互斥，可再次点击撤销。
罚时单独存储，保留原始秒数，成绩列表和详情显示判定结果，原始秒数仍保存在记录中。当前没有云同步。

SVG 由 Rust 生成，App 使用禁止 JavaScript 的 WKWebView 显示。开始计时后在后台预取
下一条打乱及 SVG，两个 WebView 交替显示和预加载。停止计时后保留上一张图，直到新图
加载完成。打乱公式等待超过 250 ms 才显示「生成中…」。原生渲染和控件归
产品负责；SDK 不提供视图。首页计时页固定在一屏内，打乱图位于底部。

首页、成绩四种视图、设置、成绩详情和分组编辑共享同一淡青至靛蓝的渐变背景，列表隐藏系统滚动背景以透出渐变。

iPhone/iPad 使用同一布局，内容宽度上限 880；支持窗口宽度变化。当前尚无专门的
横屏双栏设计。维护时需检查字体放大、VoiceOver、系统深浅色及降低透明度效果。

## 冷启动

CubeginApp 在进程内持有 hasFinishedLaunch，不写入磁盘。当前按进程重启播放一次，
不加时间间隔限制；系统回收或用户划掉后的新进程都会播放，正常后台恢复不播放。首次显示时，LaunchView 在
系统深浅色背景上展示 80pt 原生四色标志：蓝块按原版缓动旋转 0→378°（1.1 秒），
再用 0.22 秒淡出。标志下方间隔 16pt 放置 108pt 宽的原版 SVG 字标，整体按完整窗口居中。
字标由 Asset Catalog 随系统深浅色自动切换为深色或白色。黄红绿保持静止，蓝块在
前景。图形比例、圆角和颜色来自历史 SVG。

开屏先独立渲染，旋转期间不创建计时页。旋转结束后保持最终姿态，再创建计时页和读取成绩，
页面出现并留出 80ms 布局时间后淡出；淡出完成才启动后台打乱及后续 WebView 加载。
开屏结束前禁用计时页交互并隐藏其辅助功能元素，避免页面初始化打断旋转。
后台返回不重播，开屏中进入后台则直接结束，避免回来继续等待。开启减少动态效果时
显示静止 18° 姿态并短淡出。系统先显示 LaunchScreen.storyboard，布局和蓝块 0° 姿态匹配动画首帧；
它使用 Asset Catalog 的 @3x PNG（字标含深浅色变体），无需等待 SwiftUI 或 SDK 初始化。
动画页仍用原生矢量 Logo 和 SVG 字标。两页都按完整窗口居中，避免安全区差异导致位置跳变。
工程显式声明横竖屏方向；iPad 还支持倒置竖屏，系统启动页与 SwiftUI 保持一致。

Debug 构建可传入 `--hold-launch-screen`：静止在最终 18° 姿态供视觉调试，后台返回
也保持开屏。Release 忽略该参数。App 模块名为 CubeginApp，避免与 SDK Cubegin
在大小写不敏感的文件系统中冲突。

## 主导航

AppTabsView 使用系统原生 TabView，三个 Tab 共享同一份 TimerModel。iPhone 首页不创建
NavigationStack，也没有品牌工具栏，避免顶部额外占位；iPad 所有窗口宽度都保留 NavigationStack，
并显式显示 navigationBar，让系统为窗口控制按钮保留顶部空间，避免紧凑窗口中遮挡项目菜单。
仅将无背景训练按钮放在顶部右侧，项目菜单始终放在内容顶部下一行居中，避免挤压 Tab 栏。
成绩和设置各自拥有
NavigationStack，设置页使用 inline 紧凑标题，成绩根页面隐藏标题，详情保留系统返回导航。
切换页面不重新生成打乱。首页使用历史四色标志，成绩和设置使用
SF Symbols；三个图标使用 28pt 画布，SF Symbols 按当前屏幕比例渲染为模板图像，
避免系统符号配置覆盖指定尺寸。Tab 只显示图标，页面内 Label 仍显示标题。系统负责导航栏材质、
选中指示、触摸交互及辅助功能行为，不自绘玻璃胶囊或限制导航栏尺寸。
iPhone/iPad 的导航位置和布局跟随系统，不再强制 iPad 使用自定义底部胶囊。

成绩页与首页共享项目和训练状态，复用 EventPicker 与 TrainingButton，按 iPad size class
沿用首页的 iPad 导航栏规则。iPad 常规宽度下，分组、项目、视图单排显示，项目居中，分组和视图分别靠两侧页面边距，不限制为 880pt；紧凑宽度的项目和训练按钮进入导航栏，iPhone 使用两行控件。成绩页根页面不显示「成绩」标题，
分组与视图两个菜单左右对齐。iPhone 第一行保留项目和训练按钮原有布局与点击区域，不额外调整图标与胶囊的视觉对齐。四个视图筛选当前分组，分别显示单次、滚动 Ao5/Ao12、
汇总统计和单次趋势。Ao5/Ao12 去掉两端各 5%（向上取整），DNF 按最差处理；
保留部分含 DNF 则平均为 DNF，样本不足显示破折号。+2 先计入单次再参与统计。
图表横轴为组内计时顺序，DNF 保留位置但无时间点。
单次成绩使用原生 List 按需创建行，以成绩 UUID 保持身份，按日期倒序显示；组内序号从总数递减至 1。单行仅显示序号、计时和日期，最小行高 44pt。向左滑动在右侧显示 32pt 正圆红底、白色垃圾桶图标的删除按钮（与分组共用图标绘制），保留辅助功能名称，禁用整行划到底直接删除；点击按钮后二次确认，按成绩 UUID 原子持久化删除并更新各视图统计。长按一条成绩进入多选并选中该条，按住后上下拖动可连续选择起点到手指所在行的范围；靠近列表上下边缘自动滚动，回拖收缩本次范围并保留先前选择。手势通过 UIKit 长按识别器接入原生 List，普通滑动仍滚动列表。支持逐条勾选、全选、取消全选、批量移动与批量删除。多选时左上角项目入口改为全选，分组/视图/训练入口暂时禁用，底部导航隐藏并替换为居中的紧凑玻璃操作栏（已选数量靠左，右侧依次为移动、删除、关闭图标）。移动面板只列当前项目其他分组，可在面板内新建分组而不切换源分组；移动只更新 groupID，保留成绩 UUID、计时、罚时、日期和打乱，一次性持久化，完成后退出多选。批量删除同样二次确认并一次性持久化。切换分组或视图退出多选。日期按本地时区、公历判断：今天显示 HH:mm，本年其他日期显示 MM-DD，其他年份显示 yyyy-MM-dd（使用日历年而非周年）。+2 成绩包含两秒罚时并在末尾显示「+」。
设置页支持简体中文和 English 即时切换，偏好保存在 AppStorage，默认简体中文。
启动时恢复语言，通过环境 locale 传给首页、成绩和设置。

## 打乱选择

iPhone 首页左侧的无背景项目按钮打开系统 popover。右侧是哑铃按钮和暂作展示的 Cross 闪光图标，iPad 工具栏也采用相同顺序。
iPad 常规宽度（原生 TabView 顶部导航布局）项目菜单单独一行居中，哑铃按钮位于顶部
工具栏右侧并隐藏系统共享背景。紧凑宽度把小号菜单放在原生工具栏前侧，由系统安排在窗口控制按钮右边，训练图标位于同一行右侧。
未激活时为标准，激活时为训练。每次新进程默认标准，后台恢复保持当前模式。
项目图标和哑铃均使用 20pt 画布，在 44pt 高的控件行内居中。顶部 Tab 布局的工具栏右侧额外留出 20pt。
关闭时灰色、开启时强调色，透明点击区域为 32×32pt，辅助功能读出开关状态。
仅顶部导航布局的居中菜单使用 regular 控件尺寸和 body 字体，其余使用 small 和 subheadline。
条件为 iPad 且 horizontalSizeClass 为 regular，与当前原生 TabView 的默认布局规则一致。
标准项目选中态显示项目图标和箭头。训练选中态使用基础项目图标和简短训练名称。下拉列表只显示文字，保留 csTimer 全名。
选择器直接位于首页内容顶部，不再显示 CUBEGIN 与「专注每一次转动」标题块。
首页在系统安全区内使用 8pt 顶部留白，左右和底部留白为 24pt。
标准平铺 16 项，排除最少步和多盲；训练包含 94 项，按二阶、三阶各方法分组、四阶等
作为第一级，具体训练为第二级，Yau/Hoya 项目归入 4x4x4 Yau/Hoya。训练中没有 Default。
产品目录只定义名称和分组，打乱语义仍由安装的 SDK 提供。
展示名称对照 csTimer 官方中文和英文语言表，映射与本产品补充项见 [名称对照](scramble-names.md)。

UserDefaults 分别保存标准项目和训练项目；恢复时校验 ID，默认三阶和三阶 PLL。
计时或 SDK 忙碌期间禁用选择。项目 ID 驱动根视图后台刷新；训练调用 generateTraining，
返回公式后按基础项目调用 evaluateEvent 获取 SVG。成绩保留完整训练 ID，
列表和详情显示可读名称。Case 筛选尚未实现，当前使用 SDK 默认选项。
